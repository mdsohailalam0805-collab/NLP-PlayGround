# POS Tagging (Part-of-Speech Tagging)

## What is POS Tagging?

POS Tagging is the process of assigning a grammatical label to each word in a sentence.

Examples of POS tags:

* **Noun (NN)** → dog, book
* **Verb (VB)** → run, eat
* **Adjective (JJ)** → happy, beautiful
* **Adverb (RB)** → quickly, slowly
* **Pronoun (PRP)** → I, he, they

## Why do we use POS Tagging?

* Understand the role of each word in a sentence.
* Improve text analysis.
* Help in tasks such as named entity recognition, text classification, and machine translation.

## Example

Sentence:

```text
I love NLP
```

POS Tags:

```text
I      → PRP
love   → VBP
NLP    → NNP
```


## Summary

* POS Tagging assigns a grammatical tag to each word.
* It helps a computer understand sentence structure.
* It is a useful preprocessing step in many NLP applications.
